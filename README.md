# MyMusicMix

A personal Spotify music dashboard built with Flask and the Spotify Web API.

## Features

- Spotify account connection
- Now Playing
- Recent Listening
- Liked Songs
- Top Tracks
- Top Artists
- 4 Weeks, 6 Months, and 1 Year listening ranges

## Technologies

- Python
- Flask
- HTML
- CSS
- Spotify Web API
- Azure App Service
