# Ariel's Music Mix

Ariel's Music Mix is a personal Spotify dashboard built with Flask and the Spotify Web API.

It started as a simple HTML/CSS school project and was later expanded into a live web app connected to my Spotify account.

## Live Site

https://ariel-musicmix-gwecdxareudcakf0.centralus-01.azurewebsites.net

## Features

- Spotify account authentication
- Live Now Playing section
- 6 recently played tracks
- 6 liked songs with unique artists
- Top 6 tracks
- Top 6 artists
- 4 Weeks, 6 Months, and 1 Year listening ranges
- Independent time filters for Top Tracks and Top Artists
- Spotify album and artist images
- Responsive layout for desktop and mobile
- Custom music note favicon

## Technologies Used

- Python
- Flask
- HTML
- CSS
- Spotify Web API
- Spotipy
- GitHub
- GitHub Actions
